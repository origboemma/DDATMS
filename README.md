# Digital Dream Academy Training Management System (DDATMS)

## 1. Project Overview

The Digital Dream Academy Training Management System (DDATMS) is a proposed web-based application designed to organize training-related information, including learners, courses, instructors, enrolments, attendance, and basic reports.

The project is being developed as part of the IFT 399 – SIWES II programme at Digital Dream Academy.

## 2. Problem Statement

Training activities may involve managing different types of information, such as learner records, course details, enrolments, and attendance. This project will explore how a simple web-based system can bring these records together in an organized and accessible manner.

This is a proposed training project and does not assume that Digital Dream Academy currently experiences these problems.

## 3. Project Objectives

The objectives are to:

- Develop a simple web-based training management application.
- Organize learner and course records.
- Manage course enrolments.
- Record and view attendance.
- Display basic dashboard information.
- Generate simple reports.
- Apply software development, database management, testing, and documentation skills.

## 4. Proposed Features

The initial version is planned to include:

1. Learner management.
2. Course management.
3. Instructor records.
4. Course enrolment.
5. Attendance management.
6. A basic dashboard.
7. Simple reports.

Features will be implemented gradually according to the available SIWES timeframe.

## 5. Proposed Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python with Flask
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub
- **Development Environment:** Visual Studio Code

## 6. Project Scope

The project will focus on a manageable set of training management functions. Advanced features such as online payments, messaging integrations, mobile applications, and complex analytics are outside the initial scope.

## 7. Development Approach

The project will follow these stages:

1. Requirements analysis.
2. Software design and project planning.
3. User interface development.
4. Application programming.
5. Database design and integration.
6. Software testing and troubleshooting.
7. Documentation and evaluation.

## 8. Project Documentation

Project requirements, design decisions, database scripts, testing materials, screenshots, and progress updates will be maintained in the project folders.

The `PROJECT_PROGRESS.md` file will serve as the main record of project status, completed tasks, outstanding work, issues, decisions, and next steps.

## 9. Project Status

**Current stage:** Initial project setup and documentation.

**Development approach: Incremental development, testing, and documentation.

**Development priority:** Complete a simple, functional, tested, and documented application within the available timeframe.
